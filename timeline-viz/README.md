# Film Circulation Timeline — React + D3 App

Interactive visualisation of how films circulate through the festival circuit over time.

## Setup

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # Production build -> dist/
```

## Architecture

- **App.jsx** — State management, data loading, tab routing, filter state
- **FilterControls.jsx** — Filter dropdowns/inputs (country, genre, year range, sort)
- **Timeline.jsx** — D3 imperative rendering of film rows via useRef/useEffect
- **filmRow.js** — Shared utility: renders one film's timeline into an SVG
- **InsightsPanel.jsx** — Auto-computed stats from currently filtered films

D3 integration: React owns containers (`<div ref>`), D3 owns SVG internals. On prop change, D3 clears and re-renders.

## Data

`public/timeline_data.json` is generated by `database/timeline_extract.py`. To update:

```bash
python database/timeline_extract.py
cp viz/timeline_data.json timeline-viz/public/
```

## Tabs

1. **Most Traveled** — Top films by festival count, paginated, with filters and insights panel
2. **Search Film** — Autocomplete search with expanded single-film timeline view
3. **Compare** — Side-by-side timelines for up to 10 films with summary table
4. **Aggregate** — Production year x screening year heatmap + duration distribution chart
