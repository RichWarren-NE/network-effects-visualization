# Network Effects Dashboard

Unified interactive research tool for exploring short film circulation patterns across international festival networks. Integrates three visualisations — network graph, timeline, and geographic map — with master filtering.

## Setup

```bash
npm install
```

### Data Files

The dashboard expects three JSON files in `public/`:

- `network_data_enhanced.json` — Festival network graph (nodes, edges, communities)
- `timeline_data.json` — Film circulation timelines (754 films with screening events)
- `geo_data.json` — Geographic mobility data (production/screening countries, flows)

These are generated by scripts in the `database/` directory.

## Deployment

### Vercel

```bash
npm i -g vercel
cd dashboard
vercel
```

Set the build command to `npm run build` and output directory to `dist`. Vercel auto-detects Vite projects.

### Netlify

1. Push to a Git repository
2. Connect the repository in Netlify
3. Set build command: `npm run build`
4. Set publish directory: `dist`

Or use the CLI:

```bash
npm i -g netlify-cli
cd dashboard
netlify deploy --prod --dir=dist
```

### GitHub Pages

Add to `vite.config.js`:

```js
export default defineConfig({
  base: '/network-effects-viz/',
  // ...
})
```

Build and deploy to `gh-pages` branch:

```bash
npm run build
npx gh-pages -d dist
```

### Static Hosting

The `dist/` directory is fully static. Copy it to any web server (Apache, Nginx, S3, etc.). No server-side rendering required.

## Architecture

```
src/
├── contexts/
│   ├── FilterContext.jsx    # Global filter state (year, country, genre, etc.)
│   └── DataContext.jsx      # Loads and provides all three datasets
├── hooks/
│   └── useFilteredData.js   # Memoised cross-dataset filtering
├── components/
│   ├── Header.jsx           # Top bar with title, stats, status, guide button
│   ├── Sidebar.jsx          # Left panel wrapper
│   ├── FilterControls.jsx   # Master filter controls (debounced search)
│   ├── QuickStats.jsx       # Live statistics summary
│   ├── TabContainer.jsx     # Tab switcher with lazy loading + empty state
│   ├── NetworkTab.jsx       # D3 force-directed network graph (Canvas)
│   ├── TimelineTab.jsx      # D3 film circulation timeline
│   ├── GeoTab.jsx           # Plotly choropleth and flow maps
│   ├── AboutModal.jsx       # Methodology, data source, and citation
│   ├── ExportModal.jsx      # CSV/JSON/PNG/SVG export with toast notifications
│   └── UserGuide.jsx        # Accordion-style user guide
├── App.jsx                  # Root layout with skeleton loading
├── App.css                  # All dashboard styles
└── main.jsx                 # Entry point with context providers
```

### State Management

- **FilterContext**: Holds year range, selected countries/genres, event type, search query. All tabs subscribe to the same filters.
- **DataContext**: Loads all three JSON files in parallel. Provides loading/error state.
- **useFilteredData**: Memoised hook that filters timeline films, computes network subgraphs, and derives quick statistics from current filter state.

### Visualisation Tabs

1. **Network Graph** — Canvas-rendered D3 force layout. Nodes sized by film count, coloured by festival tier (A-list, regional, specialist, emerging). Drag to reposition, hover for details.
2. **Timeline** — SVG-rendered film circulation rows. Sorted by festivals/awards/span. Paginated at 40 films per page. Colour-coded by screening status.
3. **Geographic Map** — Plotly.js choropleths (production/screening), flow arcs, and period comparison. Click countries for detail panel.

### Features

- Master filters apply across all three tabs
- Debounced search input (500ms) for responsive filtering
- Save/load custom filter configurations (persisted in localStorage)
- Export filtered data as CSV, JSON, PNG (300 DPI), or SVG
- CSV exports include metadata headers with filter summary and citation
- Toast notifications for export success/failure
- Friendly empty state with reset button when no results match
- Skeleton loading screen during initial data fetch
- Lazy-loaded tabs to avoid rendering inactive visualisations
- Accordion-style user guide accessible from header
- Responsive layout (tested at 1920x1080 and 2560x1440)

## Troubleshooting

- **Blank network graph**: Check browser console. Ensure `network_data_enhanced.json` loaded. Try widening year range filter.
- **Slow initial load**: Three JSON files (~3 MB total) load in parallel. First load may take a few seconds.
- **Plotly chunk warning**: The GeoTab bundles Plotly.js (~5 MB). This is expected and already code-split via lazy import.
- **No films matching filters**: An empty state with a reset button appears automatically. Click it to clear all filters.
- **Export not working**: Ensure a visualisation tab is active before exporting PNG/SVG. Check browser console for errors.

## Data Source

Circulation data provided by Miralot via Encounters Film Festival (Bristol, UK). 754 films, 393 festivals, 4,445 screenings, 1998–2026.
