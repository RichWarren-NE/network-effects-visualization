NETWORK EFFECTS METHODOLOGY - KEY POINTS

PROJECT OVERVIEW:
- Researching how short films circulate through festival networks
- Data shows filmmaker journeys and festival connections
- Emphasis on film mobility (how films move between festivals)

DATA FOCUS:
- UK-centric: Encounters Film Festival (Bristol) as anchor
- 749 films across 393 festivals (1998-2026)
- International circulation patterns

VISUALISATION GOALS:
1. Network graphs - festival connections via shared films
2. Timeline - how films circulate over time
3. Geographic heat maps - film mobility across countries

DESIGN PRINCIPLES:
- Mobility-focused: track how films move between festivals
- Simple, clean visualisations (not cluttered)
- Professional research tool (not flashy)
- UK/European focus (prioritise UK festivals in visuals)

FUTURE EXPANSION:
- Will include anonymised rejection data (GDPR-compliant)
- Database designed to accommodate this later
- Following aggregation thresholds (minimum 5 films per pattern)

KEY RESEARCHERS:
- Loist & Samoilova (2023) - festival network analysis methodology
- Focus on subcircuits (how films cluster by genre/type)
