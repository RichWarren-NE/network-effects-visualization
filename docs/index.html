About this tool: Built as part of the Network Effects research project examining film festival networks as talent development pathways. Data sourced via Encounters Film Festival (Bristol) and Miralot. Analysis follows the subcircuit methodology developed by Loist & Samoilova (2023). Connected live to a PostgreSQL database — visualisations always reflect the latest data.
